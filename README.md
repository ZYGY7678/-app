# מסילת לילה — Rail Runner

משחק ארקייד מקורי לאנדרואיד 11 ומעלה, בהשראת משחקי התחמקות מהירים על מסילות.

## מה יש במשחק

- שש מסילות עם רכבות שמגיעות משני הכיוונים
- שליטה בהחלקה למעלה/למטה או בכפתורי מסך גדולים וברורים
- מטבעות שמגדילים את הניקוד
- איסוף מגן שמגן מפגיעה אחת
- קושי שעולה בהדרגה והכפלת ניקוד עד ×5
- שמירת שיא מקומית
- מסך פתיחה, השהיה וסיום משחק
- עיצוב כהה, מודרני ונעים לעין
- ללא פרסומות, ללא הרשאות אחסון וללא צורך באינטרנט

## תאימות

- minSdk: 30 (Android 11)
- targetSdk: 30
- Java 17
- Android Gradle Plugin 8.5.2

## בנייה

GitHub Actions בונה APK חתום להתקנה (debug ו-release) ומעלה אותם כ-artifacts בשם RailRunner-APKs.
