# BookFlow Reader

קורא ספרים מודרני לאנדרואיד, עם דגש על חוויית קריאה נוחה ועיצוב נקי.

## פורמטים
- PDF
- EPUB
- TXT
- HTML / HTM
- FB2

## יכולות
- פתיחת קבצים דרך Android Storage Access Framework, ללא צורך בהרשאת אחסון רחבה
- ספרייה עם ספרים אחרונים והמשך קריאה
- שמירת מיקום קריאה אוטומטית
- סימניות
- חיפוש בתוך הספר
- מצב יום, קרם, לילה ו-AMOLED
- שינוי גודל גופן, מרווח שורות ושוליים
- בחירת גופן Serif / Sans
- זיהוי כיוון טקסט והתאמה לעברית
- נעילת מסך בזמן קריאה
- תצוגת PDF בעמודים
- ממשק RTL ידידותי
- כפתור פתיחה מהיר וקבצי ספרים גם מאפליקציות אחרות

## Build
ה-workflow של GitHub Actions בונה Debug ו-Release ומעלה את קבצי ה-APK כ-artifacts.
